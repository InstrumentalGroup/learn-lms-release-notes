## Theme modules

**Course content (versions 1 and 2)**

- You can regenerate a learner's certificate PDF by adding `?recert=1` to the end of the course page address. Use it after you change a certificate template, because learners otherwise keep getting the PDF that was already created. Learners who don't use this address see no change.
- There are no new module settings.

**Certificate page template**

- The certificate design area now matches the printed page: A4 at 794 × 1123 px (portrait) or 1123 × 794 px (landscape). If you built a custom certificate layout in the HubSpot editor, it now lines up with the PDF.

## Course pages and certificates

- Custom certificate layouts are rendered at the same size you see in the editor, at higher resolution.
- Certificate images are no longer stretched, and custom backgrounds fill the whole page.
- Links to HubSpot and your default site address now follow your portal's data center (US or EU). EU portals get the correct `hs-sites-eu1.com` domain option and links to `app-eu1.hubspot.com`.

## Fixes

- Creating a new course no longer opens a page that says **"This page's template is missing"** on accounts that installed Learn LMS before the newer course template existed. The app now uses the course template your portal actually has. If none is available, you see an error instead of a broken page.

## Action required

- None for most accounts.
- If an existing course page already shows "This page's template is missing", this release does not repair it. Contact support and we will update the template files in your portal.
- After upgrading, regenerate certificates that were created with an older layout by opening the course page with `?recert=1`.
