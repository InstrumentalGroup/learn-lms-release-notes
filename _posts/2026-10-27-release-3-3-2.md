## Theme modules

**Course content (version 2)**

- New setting to place the **Mark lesson as complete** and **Next lesson** buttons at the top or the bottom of a lesson. The default is bottom. **Finish course** always stays at the bottom. Field descriptions were clarified.

**Courses list and Featured courses**

- Page 2 and later of the list no longer show "Untitled Course", blank images or "#" links.
- The Featured courses carousel no longer scrolls automatically when the page loads.
- Category filter checkboxes no longer interfere with each other when a page has more than one list.

**All course modules**

- Several course modules on one page no longer share pagination, popups and embedded content.

**My courses**

- Card images use a 16:9 ratio instead of a fixed height. Developers can change the ratio with the `--lms-card-aspect-ratio` style variable.

**Main menu**

- With **Highlight the current section** on, every copy of the menu (desktop and mobile) is now highlighted.

## Course pages and certificates

- A course page can be migrated from Course content version 1 to version 2. A preview mode shows the result first, and the migration creates a draft copy so the live page is untouched.

## Action required

- None.
