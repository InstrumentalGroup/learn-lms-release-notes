This release also covers the changes made since 3.3.4.

## Theme modules

**Course content (versions 1 and 2)**

- The app now records how many seconds each learner watches in a lesson video. This is stored in Learn LMS and is not yet reported to HubSpot.
- A lesson remembers whether its video was played. Watching the video unlocks the **Next lesson** button.
- New support for **Livid** videos as a lesson video source.

**Quiz**

- Hints are shown only after an answer is wrong.
- Hints follow the hint settings you choose in the module fields.

## Course pages and certificates

- Certificate downloads and regeneration: see the 3.3.4 notes. Nothing further changed here.

## SCORM courses

- SCORM launches are now checked. A course that is disabled, not installed, or linked to an inactive course no longer launches.
- SCORM progress can only be saved for a learner who launched the course, and only for that course. Progress can no longer be written or read for other learners.
- If a SCORM course is opened without a signed-in learner, the package still plays but nothing is saved.
- SCORM progress now also updates the learner's **Enrollment**, so SCORM learners get a status and a progress percentage like other learners. Completed or passed SCORM courses show as completed at 100%.
- Progress saves from several browser tabs, and the final save when a tab is closed, no longer overwrite each other or get lost.
- After a SCORM upload, the course keeps its new page link. Before, the old link could return about 15 seconds later.

## Courses and HubSpot sync

- A change made in the app that hasn't synced yet is no longer overwritten by an older HubSpot update to the same course.
- Subscription management: new back-end support for managing subscriptions.

## Moving course pages to Course content v2

The tool that creates a Course content v2 page from a v1 page was improved:

- It works with **custom course templates**, for example `11th-course.html`, as long as the page uses the v1 Course content module. The new page uses the `coursev2.html` template in the same theme, or the template you choose.
- The result includes a direct link to open the new page in the HubSpot editor.
- The new page is always a **draft**. Review it before you publish it.
- If a template can't be used as is, the result includes a warning.

## Fixes

- See the SCORM and sync items above.

## Action required

- Upload the updated theme files to your portal to get the video, quiz and Livid changes. The `coursev2.html` template and the v2 Course content module must be in the portal's theme before a page can be moved to v2.
- None otherwise.
