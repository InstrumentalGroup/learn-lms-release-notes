Each release lists what changed in the app and, separately, which **theme modules** changed. Theme modules are the building blocks you add to your HubSpot pages, such as Course content, Courses list, My courses and the menus.

Every release page has these sections:

- **Theme modules**: changes to modules and templates that appear in the HubSpot page editor.
- **Course pages and certificates**: changes to how courses and certificates behave.
- **Fixes**: problems that were corrected.
- **Action required**: anything you need to do. Most releases have none.
